# Swiper Library

Version: 12.0.3
License: MIT
Website: https://swiperjs.com/

## Files

- `swiper-bundle.min.css` - Complete Swiper CSS (14KB)
- `swiper-bundle.min.js` - Complete Swiper JavaScript with all modules (151KB)

## Usage

These files are automatically enqueued by the `LS_Plugin\Carousel` class when the carousel block is present on a page.

## Updates

To update Swiper to a newer version:

1. Download from https://cdn.jsdelivr.net/npm/swiper@12/
2. Replace the files in this directory
3. Update version number in `inc/class-carousel.php`
